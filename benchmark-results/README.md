# Benchmark results

The scheduled [full benchmark workflow](../.github/workflows/benchmark.yml)
stores its JSON output in this directory. Each result file uses its UTC run
date and time in the form `benchmark-YYYY-MM-DDTHH-MM-SSZ.json` so historical
runs remain available for comparison.

The repository's [main README](../README.md) links directly to the newest
result produced by the workflow.
